# Автокликер

Автокликер для Windows: выбирает окно, отправляет в него клики мыши или нажатия
клавиш со случайным интервалом и разбросом позиции. Работает через `PostMessage`,
поэтому не двигает реальный курсор и не требует, чтобы окно было на переднем плане.

## Возможности

- Клик левой, правой или средней кнопкой в заданную точку окна со случайным разбросом.
- Нажатие клавиш: специальные, F1–F12, цифры, латиница, кириллица (ЙЦУКЕН),
  а также любая клавиша через «Нажать клавишу…» — запоминается VK-код и символ
  в активной раскладке.
- Два способа отправки клавиши:
  - **Нажатие клавиши** (`WM_KEYDOWN`/`WM_KEYUP`) — отправляется код клавиши,
    итоговый символ зависит от раскладки целевого окна. Подходит для игр.
  - **Символ** (`WM_CHAR`) — отправляется сам символ независимо от раскладки
    окна. Подходит для текстовых полей.
- Предупреждение, если выбранное окно свёрнуто, с возможностью развернуть его
  перед запуском. Во время работы статус показывает, что окно свёрнуто, а если
  окно перестаёт принимать сообщения, кликер останавливается с сообщением.
- Случайный интервал между действиями и лимит количества.
- Кнопка обновления из GitHub.

## Требования

- Windows 10/11
- Python 3.10+ (только стандартная библиотека: `tkinter`, `ctypes`)

## Запуск

- Двойной клик по `Автокликер.vbs` — запуск без окна консоли.
- Или из терминала: `python clicker.py`.

## Обновление

Кнопка **«Обновить программу»** скачивает новую версию с GitHub:

| Как запущена программа            | Что делает кнопка                                   |
|-----------------------------------|-----------------------------------------------------|
| Скрипт в клоне репозитория + git  | `git fetch` и `git pull --ff-only origin main`      |
| Скрипт без git                    | скачивает zip ветки `main` и заменяет файлы         |
| Собранный `.exe`                  | скачивает `.exe` из последнего релиза GitHub Releases |

После установки обновления программа предлагает перезапуститься.

## Сборка exe

```
pip install pyinstaller
pyinstaller Автокликер.spec
```

Готовый файл появится в `dist/Автокликер.exe`. Чтобы кнопка обновления работала
в exe-версии, выложите файл в GitHub Releases с тегом, совпадающим с `__version__`
в `clicker.py` (например `v1.1.0`). Имя файла в релизе должно быть латиницей,
например `Autoclicker.exe`: кириллические имена GitHub заменяет на `default.exe`.

Готовые сборки: https://github.com/levkastergit/Clicker/releases

## Структура

- `clicker.py` — интерфейс и логика кликера
- `winapi.py` — обёртки user32 и таблицы клавиш
- `updater.py` — проверка и установка обновлений
- `clicker.pyw` — точка входа без консоли
- `Автокликер.vbs` — запуск через `pythonw`, если Python не в PATH
- `Автокликер.spec` — конфигурация PyInstaller
