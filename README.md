# Автокликер

Автокликер для Windows: выбирает окно, отправляет в него клики мыши или нажатия
клавиш со случайным интервалом и разбросом позиции. Работает через `PostMessage`,
поэтому не двигает реальный курсор и не требует, чтобы окно было на переднем плане.

## Требования

- Windows 10/11
- Python 3.10+ (только стандартная библиотека: `tkinter`, `ctypes`)

## Запуск

- Двойной клик по `Автокликер.vbs` — запуск без окна консоли.
- Или из терминала: `python clicker.py`.

## Обновление

Кнопка **«Обновить программу»** скачивает новую версию с GitHub:

| Как запущена программа            | Что делает кнопка                                   |
|-----------------------------------|-----------------------------------------------------|
| Скрипт в клоне репозитория + git  | `git fetch` и `git pull --ff-only origin main`      |
| Скрипт без git                    | скачивает zip ветки `main` и заменяет файлы         |
| Собранный `.exe`                  | скачивает `.exe` из последнего релиза GitHub Releases |

После установки обновления программа предлагает перезапуститься.

## Сборка exe

```
pip install pyinstaller
pyinstaller Автокликер.spec
```

Готовый файл появится в `dist/Автокликер.exe`. Чтобы кнопка обновления работала
в exe-версии, выложите файл в GitHub Releases с тегом вида `v1.1.0`.

## Структура

- `clicker.py` — интерфейс и логика кликера
- `updater.py` — проверка и установка обновлений
- `clicker.pyw` — точка входа без консоли
- `Автокликер.vbs` — запуск через `pythonw`, если Python не в PATH
- `Автокликер.spec` — конфигурация PyInstaller
